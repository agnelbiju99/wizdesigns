Frequently asked questions

What exactly do I get?

How do I use it?

Download the file and open it in any browser — Chrome, Safari or Firefox. Start using it straight away; every change saves automatically in your browser.

Does it work on my phone?

Yes. It's fully mobile-optimised — open it in Chrome or Safari on Android or iPhone.

Does it need internet?

Only to load the fonts the first time. Everything else works 100% offline.

Is my data safe?

Yes. Everything is stored only on your device. Nobody else can see it — not even us.

What if I clear my browser?

Clearing browser data deletes what's saved, so use the Backup button regularly to save a JSON file. You can restore it any time.

No. It's a built-in coach that analyses the data you've logged and answers from your own numbers. That's why it needs no API key, no account and works offline.
